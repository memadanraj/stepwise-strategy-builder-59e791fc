# Stepwise Strategy Builder

A phase-by-phase strategy builder and Reelforge studio application.

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Billing

Billing is integrated with Paddle Billing. See `INTEGRATION_SETUP.md` for Paddle sandbox/live credentials, product/price IDs, and webhook setup.
